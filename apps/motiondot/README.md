# MotionDot Web

Next.js App Router 프론트엔드 + Route Handlers.

## Dev

```bash
# monorepo root
pnpm install
pnpm --filter @motiondot/web dev
pnpm --filter @motiondot/worker dev
```

- Web: http://localhost:3100
- Converter: http://localhost:3100/converter

상세 구조는 [ARCHITECTURE.md](./ARCHITECTURE.md)를 참고하세요.
